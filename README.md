# WEBDESIGN.HTMLCSS TAGS USED
This is a simple website built with HTML and CSS , including the following elements :

<!--meta--> This tag is used to give extra information about a page.
<!--Title--> This tag is used to give web page a title.
<!--h1--> This tag is used to define HTML headings.
<!--ul--> It is used to an unordered list.
<!--br--> It is used to keep a single line break.
<!--div--> It is used to group the sections of code.
<!--p--> It is used to write content.
<!--Header--> This tag is used at top of the webpage and divide it into sections.
<!---Favicon--> A small icon that appears on the left side of browser tab.
<!---Table---> Displays a list of events.
<!---Form---> The form tag is used to construct an html for user input.
<!--Images--> img tag is used to add images for visual content
<!--Hyperlink--> a tag is used to link different sections and methods.
<!--Button--> button creates a actionable button.
<!--audio--> audio tag is used to add audio file.
<!--video--> video tag is used to insert the video file.
<!--Summary--> It is used to describe the information or content.
<!--Menu--> It represents an unordered list of content.
<!--tel--> This tag is used for phone contact.
<!--mailto-->This tag is for email contact.
<!--footer--> This tag generally contains about copyright , tel information and related information.
<!--b--> bold tag is used to convert normal text into bold.
<!--body-->It contains all the elements of the page
